CIRCUIT ESCAPE — THIRD-PERSON 3D LAB

Files: index.html (self-contained game code; Three.js loads from jsDelivr CDN)

To publish: Upload index.html to a public GitHub repository root. In Settings > Pages, deploy main branch / (root). Wait for deployment, then open the GitHub Pages URL.

Requires internet access to load Three.js. No image assets or additional files needed.

Controls: Tablet: left virtual joystick to walk, drag on right to look, USE when near equipment. Desktop: WASD to walk, drag mouse to look, E to interact. Touch landscape mode recommended.

Game: Repair circuit, set 6 V, enter correct sequence, approach and use door.
